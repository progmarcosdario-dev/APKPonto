```

9. Retorna ao menu
```

## 📞 SUPPORT RÁPIDO

### Erro: "Porta em uso"

```bash
# Mudar porta em BackEnd/.env
BACKEND_PORT=3002
```

### Erro: "Não encontra Firebird"

```bash
# Verificar .env
FIREBIRD_DATABASE=C:\Apta\Dados\APTA.FDB
```

### Erro: "Senha inválida"

```bash
# Consultar Firebird
SELECT SENHA_SISTEMA FROM FUNCIONARIOS LIMIT 5
```

Mais ajuda em `GUIDE.md` e `TESTING.md`
